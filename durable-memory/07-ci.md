# CI

Same shape as lmnum, lmbio, lmparticle and lmplot: five jobs (linux-x64, linux-arm64, macos-arm64, macos-x64, windows-x64), each
running `scripts/sync-deps.sh` (a no-op here), installing `@lmctl-ai/lmctl@0.2.369` for `lmscript`, running `./test.sh` with
`LMWEATHER_TEST_NETWORK=1` (the lmplot pipelines download lmplot's release), then uploading `lmweather-<platform>[.exe]`
plus LICENSE and THIRD_PARTY_NOTICES. A `v*` tag adds the release job, which checks `--version` against the tag and attaches
the binaries with `gh release`.
